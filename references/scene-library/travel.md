# Scene Library — Travel

## Scope

Use for the journey lifecycle: pre-departure, airport/rail, waiting, transit, arrival, baggage, hotel/homestay, temporary-room routines, local connections and return.

Travel should feel like **state accumulation**, not a tourism montage.

## Domain principle

Useful travel state includes:

- luggage,
- tickets / phone / passport,
- route information,
- fatigue,
- weather,
- charging/battery,
- food/drink,
- outerwear,
- time-of-day changes.

A good travel Vlog lets these states persist.

---

## Pre-departure packing

### Realistic activity
- lay out items,
- check list,
- fold/roll,
- weigh or compress luggage,
- search for charger/document,
- close suitcase,
- reopen because something was forgotten.

### Visual anchors
- suitcase,
- packing cubes,
- charger,
- toiletry bag,
- ticket/phone,
- jacket.

### Useful Motifs
- prepare,
- search,
- choose,
- forget/recover,
- shared task.

### Relationship affordances
- one packs systematically,
- one adds last-minute items,
- one handles documents/chargers,
- one sits on suitcase or helps close it when appropriate.

### State possibilities
- loose items → packed luggage,
- unfinished search becomes departure delay.

### Routing note
If packing coordination itself is the entire story, `shared-tasks.md` may be the better primary domain.

## Airport / station entry

### Realistic activity
- navigate signs,
- pull luggage,
- check departure board,
- scan ticket/ID,
- join correct queue,
- adjust bags.

### Visual anchors
- suitcase,
- departure board,
- ticket/phone,
- signs,
- queue barriers.

### Useful Motifs
- navigate,
- search,
- wait,
- practical division of labor.

### Relationship affordances
- one navigates while one controls luggage,
- one stops to check board and the other waits,
- brief separation/rejoin can happen naturally.

### AI-friendly notes
- large hubs are visually dense,
- use medium-close behavior for identity; use wide/back for scale.

## Check-in / security / boarding control

### Realistic activity
- prepare documents,
- move items between bag/pocket,
- place luggage,
- wait turn,
- collect items afterward,
- reassemble belongings.

### Visual anchors
- tray,
- ticket/phone,
- passport/ID,
- bag,
- jacket.

### Useful Motifs
- prepare,
- wait,
- handoff,
- recover belongings.

### Physical constraints
- processes vary by location; do not invent specific branded procedures without research.

### AI-friendly notes
- many small objects and hands create complexity,
- use clean inserts and stable ownership.

## Gate / platform waiting

### Realistic activity
- find seats,
- place luggage,
- charge phone,
- buy/hold drinks,
- check board,
- change gate/platform if needed,
- sit/stand as departure approaches.

### Visual anchors
- luggage at feet,
- charging cable,
- coffee/water,
- ticket,
- board,
- seat row.

### Useful Motifs
- wait,
- observe,
- recover,
- environment interruption,
- synchronized attention.

### Relationship affordances
- one watches luggage while the other leaves briefly,
- one charges phone while the other checks updates,
- quiet fatigue can appear before the journey starts.

### State possibilities
- battery/food/fatigue change,
- boarding information creates next movement.

## Onboard train / plane / coach

### Realistic activity
- stow small bag,
- settle coat/blanket,
- adjust seat,
- look out window,
- eat/drink,
- nap,
- share screen/photo,
- retrieve item from bag carefully.

### Visual anchors
- window,
- tray table,
- seat pocket,
- cup,
- headphones,
- travel pillow.

### Useful Motifs
- settle,
- share,
- observe,
- quiet companionship,
- recover.

### Relationship affordances
- one sleeps while one stays awake,
- one gives window seat,
- one reaches for item without disturbing the other.

### AI-friendly notes
- confined spaces favor close/medium-close shots,
- avoid impossible large body movement inside seats.

## Hotel check-in / lobby

### Realistic activity
- approach desk/kiosk,
- handle phone/document,
- wait with luggage,
- receive card/key,
- move toward elevator,
- decide who carries what.

### Visual anchors
- suitcase,
- key card,
- lobby seating,
- elevator,
- phone reservation.

### Useful Motifs
- wait,
- handoff,
- prepare,
- recover.

### Relationship affordances
- one handles check-in while the other stays with luggage,
- one sits briefly while waiting,
- role division feels practical rather than staged.

### AI-friendly notes
- avoid depending on readable reservation text,
- identity shots can stay close while lobby scale is separate.

## Hotel room entry / first minutes

### Realistic activity
- try key card,
- push luggage inside,
- turn on lights,
- look around,
- open curtain,
- check view,
- choose where luggage goes,
- locate outlets,
- test bed briefly,
- remove outerwear.

### Visual anchors
- key card,
- suitcase,
- curtains,
- window,
- bedside outlet,
- chair/bench,
- room key sleeve.

### Useful Motifs
- discover,
- choose,
- search,
- recover,
- synchronized attention.

### Relationship affordances
- one explores while one handles luggage,
- one finds the view first,
- one notices practical details like outlets/water.

### State possibilities
- luggage closed → opened,
- coats/shoes come off,
- room becomes temporarily inhabited.

### AI-friendly notes
- excellent domain for medium-close lived-in behavior,
- use wide/back shot for room reveal if needed, then close reaction.

## Unpacking / charging / temporary routine

### Realistic activity
- open suitcase,
- take out only needed items,
- plug devices in,
- hang jacket,
- put toiletries near bathroom,
- separate worn/clean clothes,
- look for adapter/charger,
- prepare for shower/sleep.

### Useful Motifs
- prepare,
- search,
- divide space,
- recover.

### Relationship affordances
- different organization habits appear naturally,
- one finds adapter/charger for both,
- one uses mirror/bathroom while the other unpacks.

### State possibilities
- hotel room accumulates personal objects,
- battery/cleanliness/fatigue change.

### Realistic activity

- buy/scan ticket,

- transfer,

### Useful Motifs

## Return / end-of-trip fatigue

### Realistic activity
- repack less neatly,
- check drawers/outlets,
- collect chargers,
- weigh/close bag,
- carry souvenirs,
- sit tired at station/gate,
- sleep on return,
- unload at home.

### Useful Motifs
- finish,
- search,
- recover,
- callback.

### State possibilities
- bags fuller,
- energy lower,
- souvenirs/receipts/photos become evidence of the trip.

### Story value
Return scenes can pay off earlier packing/objects without needing a dramatic ending.

---

## Travel QC

Before using a Travel scene:
- Does luggage/document/time/fatigue state persist?
- Does travel behavior reflect actual spatial constraints?
- Are transit and hotel moments more than scenic montage?
- Are practical behaviors allowed to carry relationship meaning?
- Are busy hubs and large environments separated from face-critical shots when helpful?
