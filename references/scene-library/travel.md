# Scene Library — Travel

## Scope

Use for the journey lifecycle: packing, airport/rail, waiting, transit, arrival, hotel/homestay, destination routine and return.

## Subspace map

- Pre-departure packing
- Airport / station entry
- Security / check-in / ticket handling
- Gate / platform wait
- In-transit seat/window
- Arrival / baggage
- Hotel check-in / room entry
- Unpacking / charging / shower queue / window reveal
- Local street / transport connection
- Departure / return fatigue

## Domain rule

Travel should feel cumulative: luggage, tickets, fatigue, weather, charging, food and route decisions should create state.

## AI notes

Transit hubs are visually busy. Use inserts and medium-close behavior for identity, and reserve wides for movement/space.
