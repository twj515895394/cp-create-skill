# Scene Library — Shared Tasks

## Scope

Use when **doing something together** is the main story engine.

Examples:
- cooking a meal as a joint task,
- packing,
- deep cleaning,
- moving,
- assembling furniture,
- repairing,
- shopping from a list,
- pet care,
- preparing for a date/event,
- organizing a room.

Do not route here merely because a task appears inside another scene.

Use Shared Tasks when the viewer is meant to notice:
- division of labor,
- coordination,
- mistake/correction,
- teaching,
- waiting,
- handoff,
- completion state.

## Domain principle

A shared task naturally creates:

> objective → role split → attempt → friction/mistake → correction → completion / aftermath

This is a possibility, not a mandatory formula.

The key is that the **task changes state visibly**.

## Cooking as a joint task

Route here instead of Home Life when the focus is teamwork, process or failure/recovery.

### Realistic activity
- decide roles,
- prep different ingredients,
- ask for/hand over tools,
- discover missing ingredient,
- adjust seasoning,
- clean while the other finishes,
- plate together.

### Visual anchors
- recipe/phone,
- cutting board,
- bowls,
- utensils,
- ingredients,
- towel.

### Useful Motifs
- divide roles,
- attempt,
- fail/retry,
- handoff,
- compare,
- finish.

### Relationship affordances
- one is more systematic,
- one improvises,
- one corrects gently,
- one finishes cleanup without announcement.

### State possibilities
- ingredients → prepared food,
- clean counter → temporary mess → partial cleanup,
- role leadership may shift.

### AI-friendly notes
- keep tool/hand ownership stable,
- separate fine handwork from face-critical reactions when needed.

## Packing for a trip

### Realistic activity
- create list,
- lay items out,
- decide what stays/goes,
- compress/fold,
- search for charger/document,
- close bag,
- reopen after remembering something.

### Useful Motifs
- prepare,
- choose,
- search,
- forget/recover,
- role division.

### Relationship affordances
- one overpacks,
- one checks essentials,
- one handles electronics/documents,
- one compromises on space.

### State possibilities
- loose objects → packed bag,
- uncertainty → ready-to-leave state.

### Routing note
If the scene is mainly about airport/hotel/journey state, Travel is Primary. Shared Tasks is Primary only while packing coordination is the story.

## Cleaning / reorganizing

### Realistic activity
- sort keep/discard,
- move objects,
- wipe surfaces,
- discover old item,
- disagree lightly about where something belongs,
- finish one zone,
- sit/rest afterward.

### Visual anchors
- storage boxes,
- cloth,
- trash/recycle bag,
- shelves,
- labels,
- old object/photo.

### Useful Motifs
- sort/choose,
- discover,
- shared task,
- finish,
- callback.

### State possibilities
- clutter → order,
- found object creates new information/memory,
- energy drops.

### AI-friendly notes
- avoid huge room transformations in one continuous clip,
- show before / work / after as separate states.

## Shopping mission / list completion

### Realistic activity
- split list,
- separate briefly,
- compare items,
- return with wrong/extra item,
- check off list,
- carry bags afterward.

### Useful Motifs
- search,
- choose,
- divide roles,
- miss/recover,
- finish.

### Routing note
If the interest is primarily in supermarket/store behavior, City Daily can be Primary. Use Shared Tasks when completing the list/mission is the narrative engine.

## Assemble / repair

### Realistic activity
- unpack parts/tools,
- read diagram,
- sort hardware,
- hold piece in place,
- tighten/attach,
- realize orientation is wrong,
- undo/retry,
- test finished result,
- clean leftover packaging.

### Visual anchors
- instruction sheet,
- screws/fasteners,
- screwdriver/tool,
- parts,
- packaging.

### Useful Motifs
- attempt,
- fail/retry,
- teach,
- handoff,
- finish.

### Relationship affordances
- one reads instructions, one starts too early,
- one holds while the other fixes,
- mistake reveals patience/temperament,
- success creates earned payoff.

### AI-friendly notes
- complex assembly transformations should be broken into clear states,
- tiny hardware should not be story-critical if visual legibility is weak.

## Moving / room setup

### Realistic activity
- label/identify boxes,
- carry,
- decide placement,
- open priority box,
- discover item,
- sit among boxes,
- assemble basic area,
- order food/rest after.

### Visual anchors
- boxes,
- tape,
- marker,
- furniture,
- reusable bags,
- takeout.

### Useful Motifs
- carry,
- choose,
- shared task,
- recover,
- finish.

### State possibilities
- empty/new room → partially inhabited,
- boxes decrease,
- fatigue increases.

### AI-friendly notes
- use several stable room states rather than magical full-room reconfiguration.

## Pet care

### Realistic activity
- prepare food/water,
- attach leash,
- clean,
- play/train,
- pack supplies,
- respond to animal movement,
- settle afterward.

### Useful Motifs
- prepare,
- care,
- fail/retry,
- shared attention.

### Physical constraints
- animal behavior is less controllable,
- do not require precise simultaneous human/animal choreography unless necessary.

### AI-friendly notes
- simplify human action when animal motion is important,
- use reaction shots separately.

## Event/date preparation

### Realistic activity
- choose outfit/object,
- prepare bag/gift,
- wrap/package,
- check time,
- clean small area,
- rehearse/plan briefly,
- realize something is missing.

### Useful Motifs
- prepare,
- choose,
- search,
- surprise,
- wait.

### Routing note
If the holiday/anniversary ritual itself is the story engine, Holidays / Special Days may be Primary.

---

## Shared Tasks QC

Before routing here:
- Is the task itself what creates the story?
- Does role division matter?
- Does the task visibly change state?
- Would the scene still work if moved to another physical location?
  - If yes, Shared Tasks is probably the correct Primary Domain.
- If the environment/venue is what really drives behavior, route to that domain instead.
