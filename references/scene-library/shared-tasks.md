# Scene Library — Shared Tasks

## Scope

Use when the **task itself** is the story engine: cooking, packing, cleaning, shopping mission, moving, pet care, repair, preparation or organizing.

## Task map

- Cook a meal
- Pack for a trip
- Clean / reorganize
- Buy items from a list
- Assemble / repair something
- Move boxes / set up a room
- Care for a pet
- Prepare for an event/date

## Domain rule

A shared task should generate division of labor, mistakes, correction, waiting, handoff and completion state.

Do not route here just because a task happens inside another domain; use it when coordination is the creative focus.
