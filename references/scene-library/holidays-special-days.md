# Scene Library — Holidays / Special Days

## Scope

Use when ritual, expectation, preparation or memory tied to a special day materially drives behavior.

## Occasion map

- Birthday
- Anniversary
- New Year / countdown
- Christmas / winter holiday
- Spring Festival / family holiday
- Valentine's Day
- First night after moving
- First trip day / last trip night

## Domain rule

Do not let decorations substitute for story. Use preparation, waiting, gift/object state, timing and ritual behavior.

## AI notes

Holiday crowds/lights can increase visual complexity. Keep face-critical beats simpler when backgrounds become dense.
