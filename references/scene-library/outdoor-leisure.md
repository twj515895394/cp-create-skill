# Scene Library — Outdoor Leisure

## Scope

Use for parks, lawns, picnics, cycling, lakeside, beach, camping, trails, riverside and other open-air leisure.

## Subspace map

- Park path / lawn
- Picnic setup
- Bike route / rental point
- Lakeside / riverside
- Beach / shoreline
- Camping setup / campsite
- Trail / lookout
- Outdoor rest point

## Domain rule

Outdoor scenes gain specificity from terrain, weather, equipment and physical effort—not from generic walking and scenery.

## AI notes

Wind, water, bikes, crowds and large environments can multiply motion complexity. Separate face reactions from large-scale environmental shots when appropriate.
