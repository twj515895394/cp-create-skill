# Mother Motif Library — Scene Event Motifs

## Purpose

Mother Motifs are **cross-scene event seeds**.

They answer:

> What kind of situation gives the characters something to do, decide, notice, react to or carry forward?

They do not define location and they are not complete scripts.

## Loading rule

Load this file when:
- the setting is known but concrete events are weak,
- scenes are semantically repetitive,
- the creator needs reusable event families.

Do not load it when:
- the event is already concrete and the task is only shot/director refinement,
- the user only wants wording changes,
- Micro Moments alone can solve the realism problem.

Select a small number of motifs. Do not mechanically use every category.

## Core motifs

### Search / Navigate

**Engine:** something or somewhere is not immediately found.

Possible forms:
- find route,
- find store/seat/car/item,
- locate partner after brief separation,
- check sign/map/phone,
- realize the first direction was wrong.

Produces:
- decision,
- leadership contrast,
- delay,
- discovery,
- natural object use.

### Choose / Compare

**Engine:** two or more plausible options exist.

Possible forms:
- food,
- route,
- activity,
- item,
- photo,
- seat.

Produces:
- preference reveal,
- tiny disagreement,
- role contrast,
- decision state.

### Wait / Anticipate

**Engine:** desired action cannot happen immediately.

Possible forms:
- queue,
- food preparation,
- transport,
- person arriving,
- show/fireworks,
- loading/download.

Produces:
- micro behavior,
- observation,
- impatience/calm contrast,
- time texture.

### Share / Handoff

**Engine:** one object/resource passes between people.

Possible forms:
- drink,
- food,
- umbrella,
- phone,
- ticket,
- bag,
- headphones.

Produces:
- practical intimacy,
- hand/object continuity,
- asymmetric care.

### Compete / Race

**Engine:** both pursue the same result.

Possible forms:
- game,
- speed,
- choice,
- score,
- last item.

Produces:
- energy,
- teasing,
- clear reaction,
- winner/loser aftermath.

### Attempt / Learn

**Engine:** one or both try something unfamiliar.

Possible forms:
- new activity,
- tool,
- food,
- pose,
- game,
- route method.

Produces:
- uncertainty,
- teaching,
- role reversal,
- improvement.

### Fail / Retry

**Engine:** first attempt does not work.

Possible forms:
- wrong route,
- failed photo,
- missed catch,
- dropped/forgotten item,
- bad game attempt.

Produces:
- reaction,
- correction,
- humor,
- cooperation.

### Recover / Rest

**Engine:** previous activity has a physical or emotional cost.

Possible forms:
- sit,
- drink,
- catch breath,
- fix hair/clothes,
- slow walking pace,
- quiet pause.

Produces:
- state continuity,
- believable time,
- care opportunity,
- rhythm change.

### Care / Practical Help

**Engine:** one notices a small need and acts.

Possible forms:
- water,
- bag,
- jacket,
- shoe,
- collar,
- tissue,
- seat,
- pace adjustment.

Produces:
- relationship meaning without staged romance.

### Observe / Sneak a Look

**Engine:** one person is occupied; the other notices them or the environment.

Possible forms:
- watch partner concentrate,
- watch partner eat,
- notice fatigue,
- notice distraction,
- delayed smile after the other looks away.

Produces:
- quiet intimacy,
- reaction asymmetry,
- close observational shots.

### Record / Review

**Engine:** the couple creates or reviews a record.

Possible forms:
- photo,
- video,
- booth picture,
- map screenshot,
- ticket,
- gallery review.

Produces:
- secondary reactions,
- bad-photo humor,
- memory object.

### Prepare / Get Ready

**Engine:** something must be made ready before leaving/starting.

Possible forms:
- bag,
- clothes,
- shoes,
- tickets,
- route,
- equipment,
- food.

Produces:
- anticipation,
- division of labor,
- prop setup.

### Pack / Clean Up / Finish

**Engine:** activity produces leftovers or objects that must be handled.

Possible forms:
- throw packaging,
- pack purchases,
- fold map,
- collect belongings,
- load car,
- clear table.

Produces:
- natural endings,
- transition,
- object continuity.

### Environment Interrupts

**Engine:** environment changes the plan.

Possible forms:
- rain,
- wind,
- crowd,
- heat,
- closed route,
- noise,
- sudden announcement.

Produces:
- adaptation,
- care,
- route change,
- physical realism.

### Discover / Notice

**Engine:** something unexpectedly attracts attention.

Possible forms:
- storefront,
- animal,
- performer,
- unusual product,
- view,
- sound.

Produces:
- gaze direction,
- spontaneous route deviation,
- "one notices first" behavior.

### Miss / Misunderstand

**Engine:** information or timing briefly fails.

Possible forms:
- didn't hear,
- took wrong item,
- walked ahead,
- thought partner was following,
- wrong order.

Produces:
- small repair,
- delayed reaction,
- low-stakes comedy.

### Synchronized Attention

**Engine:** relationship is shown by both attending to the same external thing.

Possible forms:
- parade,
- animal,
- window view,
- movie,
- fireworks,
- street performance.

Produces:
- CP feeling without constant face-to-face behavior,
- quiet ending potential,
- environment/identity shot separation.

## Motif combination rule

Usually combine no more than 1–2 dominant motifs inside a short Scene Event.

Examples:
- Wait + Observe
- Attempt + Fail/Retry
- Recover + Care
- Discover + Choose
- Search + Tiny misunderstanding

More motifs do not automatically create a richer scene.

## Transformation test

A Motif is doing useful work when changing the location changes its concrete expression.

"Wait" in a theme-park queue should not look identical to "Wait" in a hotel lobby or kitchen.

Use the selected Scene Library domain to localize the motif.
